# Lesson 9. Reading a Shariah note

In this repo, Shariah labels are **notes only**.

## Labels

- **likely_ok** — checklist did not raise an obvious concern with the data on hand
- **likely_concern** — checklist flagged something you should notice
- **unclear** — not enough data
- **needs_scholar** — outside what a checklist note should decide

## Plain idea

A red note is information for you. It is not an automatic block. A green note is also not a fatwa.

## Practice

If a brief shows `likely_concern` on a bank stock, what should you still expect the desk to do with research and draft proposals?
